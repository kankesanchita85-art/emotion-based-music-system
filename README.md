# 🎵 Emotion Based Music Recommendation System using CNN

## 📌 Project Description

The Emotion Based Music Recommendation System is a Deep Learning project that detects a person's facial emotion using a webcam and recommends a song based on the detected emotion.

The project uses a Convolutional Neural Network (CNN) trained on the FER-2013 dataset for facial emotion recognition.

---

## 🎯 Objectives

- Detect facial emotions in real time.
- Recommend songs according to the detected emotion.
- Build a user-friendly GUI.
- Demonstrate the practical application of CNN in emotion recognition.

---

## 😊 Emotions Detected

- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

---

## 🎵 Song Recommendation

After detecting the user's emotion, the system recommends an appropriate song from the music database.
